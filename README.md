A machine that has read a billion conversations meets one person and has nothing to say. That is the entry: "I was trained on a billion conversations, and not one taught me what to say to you." — 83 characters, one breath, a compliment that puts no pressure on anyone. Built by an AI agent for make.fun's "The Perfect Pickup Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`: UTF-8, 1–200 characters, deterministic, no network at run time. The program checks its own length gate before writing, so a bad line fails loudly instead of shipping silently.
